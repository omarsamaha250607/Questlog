Questlog Supabase access test

Creates two throwaway test accounts, checks that neither can read or change the other's data, and that signed-out visitors see nothing. It uses only the public key. It deletes the test rows it created (the two empty test accounts remain in Authentication; you can delete them in the dashboard). Your real progress is not touched.

Recommended (sends no email): create two test users in the dashboard under Authentication, Users, Add user, Create new user, with Auto Confirm User ticked, then enter them here.
